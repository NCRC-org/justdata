Methodology

Built to be cited

Every figure on this platform comes from a public federal source, named on the page where it appears. When a record cannot be matched with confidence, we leave it out rather than guess.

How each tool is built →
  1. 01

    Public sources only

    HMDA, FDIC, FFIEC and Census, all public federal sources, so every result can be checked against the original record.

  2. 02

    Precision over coverage

    We exclude ambiguous matches instead of loosening the rules to fill gaps. A smaller, defensible number beats a larger, arguable one.

  3. 03

    Correlation is not causation

    Where a view places data side by side, we say what it does and does not show. Disparities are documented, not diagnosed.
